Ratio vs original file divides the uploaded file’s size by the output’s size, so it mixes the effect of resizing and of compression. Ratio vs raw bitmap divides width × height × 4 bytes of the output by its file size, which isolates the codec.

SSIM compares each output, decoded again, with the same resized image before compression. It is measured on luma in 8 × 8 windows with a 4 px stride; transparent pixels are placed over white. As a rough guide: 0.98 and above is visually identical, 0.95–0.98 excellent, 0.90–0.95 good, below 0.90 visible loss.

Compression time is only the encoder: every AVIF attempt during the quality search, or the whole browser-image-compression call for the JPEG. The total row’s time is wall-clock for the full run, including decoding the original.
